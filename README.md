# GearExport
GearExport es una herramienta ligera creada especialmente para jugadores que  buscan optimizar el rendimiento de su personaje (DPS, Tanque o Sanador)  utilizando Inteligencia Artificial (ChatGPT, Gemini, Claude, etc.).

GearExport is a lightweight tool created specifically for players looking to optimize their character's performance (DPS, Tank, or Healer) using Artificial Intelligence (ChatGPT, Gemini, Claude, etc.).
